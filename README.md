# MesHeures APK

Version Android privée de MesHeures 16.1.0.

- PWA MesHeures embarquée hors ligne dans l'APK
- Pulse branding
- import/export de fichiers via le sélecteur Android
- pont JS Android prêt pour notifications/caméra et futures fonctions natives
- build automatique GitHub Actions

Le workflow `Build MesHeures APK` produit `app-debug.apk` comme artifact.
